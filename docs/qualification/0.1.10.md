# FEA Expert 0.1.10 static qualification

The fixtures use Designcenter 2612.1700 and its installed Simcenter Nastran. A native batch journal imports each complete synthetic seed in a fresh directory and saves the FEM and SIM with zero unsaved items. A new native process independently reopens the SIM, checks the FEM link and steps, records file hashes and exports the solver deck. The batch solver runs a hash-identical copy in a new job directory.

The benchmark uses uniaxial engineering stress and small deformation with linear isotropic hardening. Displacement at each state, total axial reaction, signed axial stress and accumulated equivalent plastic strain are checked against load, section and the elastic/plastic equations. The synthetic restraints permit lateral contraction. During unload, stress drops while the retained plastic strain stays constant. This qualifier covers the isolated fixture and the exercised operations. CAD-associative parameter updates, contact and bolt preload, large-strain mechanics and explicit SOL 402 restart have separate acceptance cases in the [implementation plan](../linear-nonlinear-implementation-plan.md).

## Observed recovery

- SOL 101 imported and reopened cleanly in a new batch process. Live opening flagged the SIM as modified with unchanged disk hashes. The previous roles were restored without saving the test SIM.
- SOL 401 setup check accepted an export with `LGDISP=0`. Nastran reported F06 user fatal 9465 while the launcher returned zero. The witnessed small-displacement deck uses the SOL 401 value `-1`.
- SOL 401 with `sys442=2` and no connected Solution Monitor stopped at F06 system fatal 4551. A fresh job without the setting used the same exported deck and completed.
- SOL 402 with `POST=-1` produced valid F06 quantities and reached live model readback. Its OP2 and UNV had empty BatchPost catalogs and an attached result probe reported no mesh. The separately imported, saved and exported `POST=-2` variant exposed the expected OP2 results. The decks have the same operative records apart from the output setting, after excluding generated comments, identity and closure markers. The original interactive session entered a native display operation during restoration from the first live test.
