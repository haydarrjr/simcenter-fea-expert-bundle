# FEA Expert 0.1.9 NVH qualification

The synthetic test uses Hermes 2612 Build 40, Designcenter 2612.1700 and three shared frequencies, 10, 12 and 14 Hz. The native solver results were checked with [verify_native_nvh.py](../../tests/verify_native_nvh.py), which reads result metadata and independently computes the expected values. The inputs use generated channels.

| Flow | Verified operation and result |
| --- | --- |
| Load Identification | Hermes inverted the two-channel response-over-force FRF across the three frequencies with rank 2. The response and FRF node and DOF labels were identical, which allowed native identity matching. The recovered forces matched the two known complex inputs with maximum absolute error `2.172e-5 N`. |
| TPA | Hermes `FRFResponse` generated the total and individual path responses from the recovered forces and the receiver FRFs. Each path agreed with an independent cofactor solution. The coherent path sum closed to the total, and the maximum relative error against the held-out receiver was `3.264e-6`. |
| PCA | Hermes `PrincipalComponentAnalysis` consumed typed SC_H5 auto-power and complex cross-power functions. The solved reference matrix was Hermitian with two retained DOFs. At 10 Hz the principal powers were `4.73205081` and `1.26794919`. The sum of squared virtual receiver amplitudes matched the independent receiver power, `24.125`, and held over the three-frequency grid. |
| Live 2612 readback | A synthetic Vibro-Acoustic FEM/SIM was saved in an isolated native journal and reopened in the live session. Function Plotter read two force curves, three TPA displacement curves, two virtual auto-powers and two separately identified principal-component receiver spectra. All nine curves matched the bound solver datasets after conversion from SIM units. The original work and display parts were restored and the synthetic SIM file hash was unchanged. |

The result reader expects five files in order, the inverse loads, combined response, first path, second path and PCA. Supply the exact solver outputs in an environment with `h5py`. The optional `--live` input compares the live native curve values in the test SIM's metric units. The numerical TPA method uses native `FRFResponse` and the Function Plotter result data source. The dedicated TPA display scenario returned empty curves for these source bindings.
