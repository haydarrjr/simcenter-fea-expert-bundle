# FEA Expert 0.1.8 qualification

Windows Designcenter 2612.1700 and bundled Simcenter Nastran 2612 were used with independent synthetic data. The method skill references use neutral examples. No training geometries, journals or results are distributed.

| Check | Evidence |
| --- | --- |
| Save and Save As | Standalone PRT/FEM/SIM files were saved from owned batch journals with zero unsaved parts and objects. A derived SIM with an imported Mode Set was saved with `BasePart.SaveAs` to a new path. The derived SIM retains its scoped existing FEM dependency. Subsequent reopen and evidence compare the exact files and added objects. The interactive MCP sandbox still restricts direct save. |
| SRS | NXOpen AFU Time-to-SRS converted a synthetic sampled base-acceleration pulse to 11 absolute maxima over 5–55 Hz at 5% damping. A fresh native process reopened the AFUs. An independent RK4 solution of the relative oscillator equation, measured as absolute acceleration, agreed to 0.016% maximum relative error. This qualifies SRS generation and the AFU result. |
| Modal damping | SOL 103 wrote `BHH` and `K4HH` for the [synthetic oscillator](../../tests/fixtures/sol103-modal-damping.txt). The native Mode Set gave 15.915494 Hz, viscous fraction 0.02 and structural loss factor 0.06, both presence flags true. The independent values use the physical mass, damping coefficient and stiffness. |
| External superelement | The [generation](../../tests/fixtures/sol103-external-component.txt) run wrote a DMIGOP2 matrix and an assembly include. The [assembly](../../tests/fixtures/sol103-external-assembly.txt) used the exact pair. The two eigenvalues matched the [full model](../../tests/fixtures/sol103-external-full.txt) and an independent two-DOF calculation. The residual modal dataset of the assembly result OP2 imported as a native Mode Set with frequencies 6.530915 and 21.243538 Hz. The matrix OP2 was retained for the solver. |
| NVH | A native Vibro-Acoustic SIM was saved with PCA and Load Identification solution objects. The [structural transfer fixture](../../tests/fixtures/sol108-transfer-paths.txt) used two unit-excitation cases and a separate combined complex case. The two recovered loads agreed within 2.49e-6 N. The reconstructed independent third receiver matched within 2.93e-7 relative error. A Hermitian complex reference CSD reproduced the receiver power by direct propagation and principal component reconstruction. |
| BatchPost | The [SOL 111 fixture](../../tests/fixtures/sol111-psd-field.txt) produced real nodal RMS and 81 PSD states. The isolated 2612 BatchPost connector exported node/component CSV using the exact result XML, catalogue iteration indexes and explicit input units. RMS was 3.51242042 mm. All 81 PSD values in mm²/Hz agreed with the scaled independent receptance calculation to within 2e-6 relative tolerance. |
| Live Designcenter Open | The saved damping, reduced and Vibro-Acoustic SIMs opened in the same interactive 2612 process. Readback confirmed linked FEMs and unchanged file hashes, the two Mode Sets, and the native PCA/Load Identification objects. The same session independently read the generated AFU spectrum. The original work/display roles and modified state were restored after each part. |
