## Routing and portability review

The November 2026 audit reviewed skill activation, linked methods and assets, and agent entry points in AgentsAI, Codex and VS Code. The [FEA workflow](../fea-workflow.md) routes focused requests by requested outcome. The [Siemens tool routing skill](../skills/fea-sc3d-tool-routing/SKILL.md) owns native profile selection and recovery. Each engineering method stays with its owning skill. The same canonical skill tree is included in each client distribution. [ReThinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra) · [Agent Plugins manifest schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json)

The review removed model-derived BatchPost framing and display values, fixed study-specific deck examples, and replaced instructions for retired helpers with current methods. It also corrected the persistence route, isolated solver diagnosis from artifact provenance, and limited the result-export recipe to its BatchPost worker. Native findings remain scoped to their observed releases in [qualification](qualification/).
