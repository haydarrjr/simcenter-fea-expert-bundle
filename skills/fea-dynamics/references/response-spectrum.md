# Base excitation and response spectra

Use the Simcenter 3D Response Dynamics route when the task needs peak response to a base spectrum. Start from the exact modal solution and check constraints, enforced-motion DOFs, output recovery, active modes and directional effective mass. Read response solutions, events and excitations through the qualified [2612 CAE reader](../../designcenter-open-journal-authoring/references/cae-2612.md). The alternative Nastran response-spectrum solver route has its own sequence, options and deck evidence.

- For time-to-SRS conversion bind time and acceleration units, sampling, axis, polarity, initial state and decay window. Record the actual spectrum quantity, damping, frequency axis, peak convention and any envelope rule.
- For relative displacement `z` use `z'' + 2ζωₙz' + ωₙ²z = −a_b(t)`. Absolute acceleration is `z'' + a_b`. Pseudo acceleration is `ωₙ² max|z|`. Keep separate labels and compare against an independent single-DOF time integration with converged time step and decay window.
- Check the enforced DOF identity, mode cutoff, missing mass or residual treatment when supported, modal combination and directional combination. Use the applicable criteria for the actual modes and event. A peak combination does not carry phase, signed tensor history or simultaneous extrema.
- Bind the solution, event, excitation, evaluation and recovered position when reading results. For native authoring use the [runtime gate](../../fea-native-runtime-gate/SKILL.md) and qualify the exact operation. For an actual time history use [transient field histories](transient-field-history.md). For stationary input spectral densities use [random response](../../fea-random-response/SKILL.md).

In the 2612 Python AFU path, `Session.AfuManager` can create a sampled acceleration record and `AfuMathOperation.TimeToSrs` can write a separate AFU. Use the exact source index from `GetRecordIndexes` and explicitly specify damping, output axis and maximum convention. Reopen and use `GetAfuData` to obtain the timestamp and data object, then `GetEvenData` and `GetRealData` for the verified even grid. Check physical units, values and frequency coverage with an independent SDOF calculation. This operation creates the excitation spectrum. Application to a structural Response Dynamics event requires its own verified basis, event and recovered output.

For a solved, matching modal result, the 2612 Response Dynamics solution builder uses `ObjectLabel.Name` and `ReferencedSolution`. Bind the solution as active before creating a `ResponseSpectrum` event with its own `ObjectLabel.Name`. The generic solution builder `Validate()` method reported `Not yet implemented`. Verify the modal result reference beforehand, and independently read back the committed solution, event, excitation membership and any evaluated results after save/reopen.

For enforced motion, the 2612 `SEMODES 103 - Response Simulation` setup accepts the `EnforcedMotionLocation` constraint descriptor. Select SIM occurrence nodes and set the constrained components in the constraint property table. Request the modes and the required recovery in the Dynamics step. Inspect the translated `SPC`, `USET` and `RSCON` records and the actual modal OP2 before attaching it to the Response Dynamics solution. Check that the SRS covers the retained mode frequencies. Set the excitation location type to `EnforcedMotion`, bind the actual constraint `BcLabel` and verify the event membership. A table function refers to the AFU record by index, name and timestamp. Resolve the AFU companion file that the SIM will actually read and retain it with the saved SIM and result, including after Save As.

For a nodal peak evaluation, specify the result quantity, direction components and SIM output nodes in `CreatePeakValueEvaluationSettingBuilder`, then commit and call `EvaluatePeakValueResults`. Use the event's `DynamicResponse` filename to locate the RS2. In a fresh read, bind `ResultManager.CreateResponseEventResult` to that event, discover the quantity and component through the result catalogue and query nodes by label. A directional peak result can expose a scalar component in the returned result type. Confirm finite values, units and linear excitation scaling when the model basis and modal combination settings are fixed.
