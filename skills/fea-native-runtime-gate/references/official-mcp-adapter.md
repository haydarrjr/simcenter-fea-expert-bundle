# Official Siemens MCP session adapters

Use the current host-owned MCP session. Obtain the advertised tool descriptors and current target evidence before binding. The adapters call the FEA controller and receive fresh operations from the caller. They create no transport and perform no live call at import or binding.

- [Python adapter](../scripts/official_mcp_adapter.py). Add the adjacent scripts directory to the host Python import path. Construct `OfficialMcpAdapter(session, profile, catalog, observed_target, evidence_ref)` with the existing MCP ClientSession. The session uses the host's timeout policy. Call `await adapter.execute_chain(controller, steps, readback)`. The adapter serializes chains for that client session. Rebind on catalog or target change.
- [JavaScript adapter](../scripts/official_host_adapter.mjs). Supply the host's official tool dictionary, a mapping from each advertised catalog name to its exact host key, and a `controller(command, payload)` callback. The callback writes the JSON to a locally owned request file, invokes the FEA controller CLI, and returns parsed JSON. The host owns quoting, working paths and transport. Call `await adapter.executeChain(builders, readback)`. The adapter prevents overlapping chains on the same tool dictionary and session.

For v1, the Python adapter also accepts an existing client via `execute_operation` with the exact current catalog, target, caller grant and independent witness callbacks. The [CLI contract](runtime-cli.md) defines the direct-host route and v1 receipts.

For each legacy chain step, the builder receives the preceding accepted receipt, if any. Return the controller operation, fresh target-evidence reference, and hash-bound authorization for any effectful operation. Include the preceding operation ID in the successor's `depends_on`. Use one durable controller directory for the chain. The builder can derive measurements and identify the target of the next operation from the preceding observation. The independent readback callback receives the prepared request and returns the controller's target, timestamp, evidence reference and observed witnesses. A nonaccepted observation stops the chain. Reconcile uncertain effects through the controller before retrying.

For structured model-data reads, use [read verification](../../designcenter-open-model-data-read/SKILL.md) for exact requested fields, page continuity, part identity, units and error handling. The adapter's receipt records the request and native observations. Engineering acceptance still requires the applicable physical checks.
