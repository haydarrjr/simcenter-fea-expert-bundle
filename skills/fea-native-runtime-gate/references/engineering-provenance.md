Original bundle files retain MIT. Each adopted file identifies its source path. The archives carry the [Apache license](../scripts/fea_runtime/engineering/LICENSE-APACHE.txt) and the retained donor [NOTICE](../scripts/fea_runtime/engineering/NOTICE.txt). Dependencies install separately using the [Windows Python 3.12 wheel pins](../scripts/fea_runtime/engineering/requirements.txt). NumPy, SciPy and pyNastran carry BSD-family licenses. Consult each distribution's included license for its transitive components.
