# Siemens documentation

Use the host's Product Support or Siemens Help Server catalog. Use `STS_DESIGNCENTER` for NXOpen programming and `STS_SIMCENTER3D` for Pre/Post and Nastran. Specify the release and use focused terms, an exact member, solver card or error ID. Use Designcenter's documentation search only if the current profile advertises it.

Confirm the returned product, document title and resolved release. Fetch the matching topic if the snippet is insufficient. Cite the article URL and qualify evidence from a different release. Connect documented behavior to an installed API or solver run only after observing it.
