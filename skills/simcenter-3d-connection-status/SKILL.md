# Simcenter 3D connection

Use the Model Inspection profile's `dc_connection_status` on first binding or a connection symptom. Discover the native tools through the current catalog and verify the target with `part-info-tool` when it exists. A connection status alone gives no model identity. Follow the [shared recovery policy](../fea-sc3d-tool-routing/SKILL.md) if a needed reader is missing or returns `DCMCP-E002`.
