# Airframe structural verification

Bind the structural FEM hierarchy, aerodynamic discretization, spline coupling and solution state. Check load paths, mass/CG/inertia, units and coordinate systems. Scope weights, configurations and trim cases from the actual requirements.

Follow [model hierarchy and solver cards](references/airframe-model-hierarchy-and-cards.md) for SOL 144 and envelope checks. Use [load filtering](../simcenter-aerostructures-load-filtering/SKILL.md) for free-body extraction and case-set selection. Use [margin of safety](../simcenter-aerostructures-margin-of-safety/SKILL.md) for allowables and governing states. Load the specialist reference for the requested stage. Track independent force/moment balance, case completeness and evidence for each acceptance claim.
