# Visibility and selection

Choose the body tool for CAD bodies and the mesh tool for FEM/SIM meshes. Bind the intended session and object scope. Use the current `action` and filter schema. Use a single filter unless the schema and operation support a combined mesh/collector target. A missing filter can affect all entities and requires that scope to be intended. Verify the resulting visibility or selection independently where the host exposes it.
