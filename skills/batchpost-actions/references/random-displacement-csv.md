3. Discover the exact catalogue with `list`. Use [random_displacement_csv.py](../scripts/random_displacement_csv.py) to generate the XML and exact `contour` arguments. If you already opened the file under different input-unit preferences, close the task-owned file, apply preferences and reopen. Verify the fresh catalogue still matches the selected states. 4. For the single-node English 2612 layout use `verify_csv(path, plan, unit)` against the actual path in `written_files`. A PSD CSV can label its quantity columns `Unknown`; bind PSD component through the returned output filename and options, and bind each column to a distinct frequency in the current catalogue. Ambiguously rounded or duplicate frequency labels do not qualify. For RMS use the component header and aggregate state. Check every requested value and quantity unit against independent F06 or analytical evidence. Keep the raw XML, CSV and plan.

When the catalogue exposes RMS only, obtain SORT1 PSD output from the appropriate already-authorized solver job or ask for the matching source. For a SORT2 function source, use a qualified function reader. A conversion from reported RMS alone cannot reconstruct a PSD.
