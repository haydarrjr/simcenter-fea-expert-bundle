# Qualified Designcenter 2612 Python CAE operations

Runtime witness: Designcenter 2612.1700 live SIM read, separate modal setup and export, then a completed Simcenter Nastran 2612.0174 job. This catalog is for matching operations; verify the current schema, model and permissions, not every symbol again. For an unmatched operation use one targeted discovery pass. The 2606 [Python SimSolution reference](https://docs.sw.siemens.com/documentation/external/PL20251024323638784/en-US/custom_api/open_python_ref/a34617.html) and [property-table guidance](https://docs.sw.siemens.com/en-US/doc/PL20251024315444291.xid2246275/html/id1616539?audience=external) are documentation evidence, not live qualification.

| Intent | Python surface | Witness / caveat |
|---|---|---|
| Bind SIM and FEM | `Session.GetSession().Parts.BaseWork`, `.BaseDisplay`; `sim.FemPart`; part `FullPath`, `Tag`, `PartUnits`, `IsModified` | Check exact paths, tags and work/display roles. Do not use CAD-only `Parts.Work` for a SIM. |
| Read FEM ownership | `BaseFemPart.BaseFEModel`, `FullPathForAssociatedCadPart`, `BaseFEModel.MeshManager.GetMeshCollectors()`, `collector.GetMeshes()` | The recorded CAD path can be unresolved even when the FEM opens. A root collector report covers the root model only. |
| Read AFM occurrences | On `AssyFemPart`, use `BaseFEModel.GetChildren()`; each returned occurrence has `JournalIdentifier` and `Tag`. | The released 2606 Python reference identifies AFM as a separate part kind. The installed 2612.1700 binding returned the root occurrence list. Confirm hierarchy and owner scope before aggregating component meshes. |
| Read existing solution and BCs | `for q in sim.Simulation.Solutions`; `q.StepCount`; `q.GetStepByIndex(i)` (zero-based); `q.GetBcs()` and `step.GetBcs()`; `b.DescriptorName`, `b.GetSolverCardSyntax()` | Solution-level BCs can be empty while a subcase has several. Object-card text alone does not establish final set IDs, generated frame, or effective case control. |
| Resolve result reference | `q.ResultReferenceCount`; `q.GetResultReferenceByIndex(i).GetResultFile()` | Returns directory and filename on the observed native file-backed setup. Verify the file and lineage separately. |
| Inspect Response Dynamics | `sim.Simulation.ResponseSimulationManager`; explicit access to `.EvaluationSettingManager`, `.Solutions`, `.Events`, `.Excitations`, `.Sensors` | Type access observed live on 2612.1700. Iterate the Python collections directly. Batch Python readback recovered nonempty event and excitation collections; the .NET `ToArray()` spelling is unavailable in that Python binding. Empty collections and read errors carry different status. This read does not qualify builder or solve effects. |
| Create separate 103 | `sim.Simulation.CreateSolution('NX NASTRAN', 'Structural', 'SEMODES 103', name, baseline.AbstractionType)` | Only on identified working copy; reuse an existing solution only after verifying settings. Independently confirm original solution, modal tag, solution/step BCs, prerequisites and deck. |
| Set Lanczos and output | `sim.ModelingObjectPropertyTables.CreateModelingObjectPropertyTable(descriptor, 'NX NASTRAN - Structural', 'NX NASTRAN', name, 0)`; use descriptors `Real Eigenvalue - Lanczos`, `Structural Output Requests`; integer `eig.PropertyTable.SetIntegerPropertyValue('ND', requested_modes)`; `q.PropertyTable.SetNamedPropertyTablePropertyValue('Lanczos Method', eig)` and `('Output Requests', output)` | Read back with `GetNamedPropertyTablePropertyValue` and `GetIntegerPropertyValue`; independently verify the EIGRL and displacement request in the exported deck. Default output can contain other fields. |
| Export only | Exact `solution.Solve(NXOpen.CAE.SimSolution.SolveOption.WriteSolverInputFile, NXOpen.CAE.SimSolution.SetupCheckOption.CompleteCheckAndOutputErrors)` | Use the [runtime gate](../../fea-native-runtime-gate/SKILL.md) and its fixed template; never substitute a solve/submit enum. Preflight the default target beside the SIM and any configured output override. Accept only the fresh intended artifact and unchanged baseline. |

Use `main(args)` with return data on live execute, and omit the tool envelope `args` on the observed 2612 build: forwarding it produced a Python arity mismatch. Use literal typed values bound to the exact payload digest. No `getattr`, `dir`, `ord`, dynamic imports or shell. For byte iteration use `.encode('ascii')` only for known ASCII card text. A sandbox stdout report, export file and independent live readback are distinct witnesses. See the [reusable read journal](../scripts/read_cae_2612.py).

Bind the returned identity and inspect `field_errors` before interpreting each quantity. Keep empty collections and failed field reads distinct. The 2612.1700 MCP class index missed CAE classes that the live Python journal used successfully. Use the applicable [Siemens Python AFM reference](https://docs.sw.siemens.com/documentation/external/PL20251024323638784/en-US/custom_api/nxopen_python_ref/a26413.html) and a narrow read for an unqualified member.

For authorized standalone models, the [native persistence method](../../fea-native-runtime-gate/references/native-persistence.md) gives the verified Windows batch save and fresh-process reopen route.
