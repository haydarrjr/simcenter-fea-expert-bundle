# Solver deck import and round trip on Designcenter 2612

Use this workflow for a complete, independent Nastran input with known coherent units. This route creates a solver-backed FEM/SIM. Use the CAD-associative preparation route when geometry linkage or parameter changes are required. [Siemens solver-file import](https://docs.sw.siemens.com/en-US/doc/PL20251024315444291.advanced_sim_tutorial/html/xid1844998?audience=external) · [NXOpen Python CaeSession](https://docs.sw.siemens.com/documentation/external/PL20251024323638784/en-US/custom_api/nxopen_python_ref/a26969.html)

1. In isolated 2612.1700 `run_journal.exe`, get the data container from `session.CaeSession.GetDataContainer()`. Use `AddString` for `solverInputFileFullPath`, `femFileName` and `simFileName`. Bind them to absolute paths with different FEM and SIM base names. Compare the translator's unit summary and the exported unit header with the intended coherent unit system.
2. Use `AddLogical` for the import scope. For a structural deck, select the scopes it needs from `createSolution`, `importNonBulkData`, `importExecutiveControl`, `importCaseControl`, `importBulkData`, `importGrids`, `importElements`, `importMaterials`, `importPhysProps`, `importLoads`, `importConstraints` and `importOutputRequests`. Use `CaeSession.ImportSimulation("NX NASTRAN", options)` and dispose of the container. Check the returned part type, exact FEM/SIM paths, links, solution family and step count. Inspect the translator report for skipped cards. A FEM return alone does not establish SIM creation.
3. Save the FEM before the SIM using [native persistence](../../fea-native-runtime-gate/references/native-persistence.md). In a fresh batch process reopen the exact SIM, verify dependency hashes and effective native state, then export with `WriteSolverInputFile` and setup check. Inspect the new deck for effective constraints, loads, nonlinear state controls, material and requested output, including remapped set IDs.
4. For live reopen, bind the original session and inventory its loaded parts and roles. Check for same-name parts from another directory before opening. Use an empty or isolated work session if the existing parts cannot be safely released. Independently read the opened paths, FEM link, solution steps and requested attached result states through Designcenter Open and Model Inspection. Restore the original roles after the check. An imported SIM can report modified on interactive open even when the fresh batch reopen was clean. Verify saved-file hashes before and after the check.
5. Solve the unchanged exported deck in a fresh job and validate results using [Solution Sequence](../../fea-solver-investigation/references/solution-sequence.md). Preserve the seed, exported deck, solver termination, resolved subcase and independent comparison.
