# Solver deck import and round trip on Designcenter 2612

Use this workflow for a complete, independent Nastran input with known coherent units. This route creates a solver-backed FEM/SIM. Use the CAD-associative preparation route when geometry linkage or parameter changes are required. [Siemens solver-file import](https://docs.sw.siemens.com/en-US/doc/PL20251024315444291.advanced_sim_tutorial/html/xid1844998?audience=external) · [NXOpen Python CaeSession](https://docs.sw.siemens.com/documentation/external/PL20251024323638784/en-US/custom_api/nxopen_python_ref/a26969.html)

1. In isolated 2612.1700 `run_journal.exe`, get the data container from `session.CaeSession.GetDataContainer()`. Use `AddString` for `solverInputFileFullPath`, `femFileName` and `simFileName`. Bind them to absolute paths with different FEM and SIM base names. In the witnessed input route the translator reported N–m–kg–°C. Verify its unit summary and the exported unit header for every import.
2. Use `AddLogical` for the import scope. For an ordinary structural deck the witnessed scope includes `createSolution`, `importNonBulkData`, `importExecutiveControl`, `importCaseControl`, `importBulkData`, `importGrids`, `importElements`, `importMaterials`, `importPhysProps`, `importLoads`, `importConstraints` and `importOutputRequests`. Use `CaeSession.ImportSimulation("NX NASTRAN", options)` and dispose of the container. Check the returned part type, exact FEM/SIM paths, links, solution family and step count. Inspect the translator report for skipped cards. A FEM return alone does not establish SIM creation.
3. Save the FEM before the SIM using [native persistence](../../fea-native-runtime-gate/references/native-persistence.md). In a fresh batch process reopen the exact SIM, verify dependency hashes and effective native state, then export with `WriteSolverInputFile` and setup check. Inspect the new deck for effective constraints, loads, nonlinear state controls, material and requested output, including remapped set IDs.
4. For live reopen, bind the original session first. Independently read the saved synthetic or owned model through Designcenter Open and Model Inspection, then restore the original roles. An imported SIM can report modified on interactive open even when the fresh batch reopen was clean. Record that observation, verify disk hashes, and restore without saving interactive changes from the readback.
5. Solve the unchanged exported deck in a fresh job and validate results using [Solution Sequence](../../fea-solver-investigation/references/solution-sequence.md). Preserve the seed, exported deck, solver termination, resolved subcase and independent comparison.
