# Linear static structural analysis

Bind the load path and engineering quantity. Check whether material response, kinematics and interface state support a constant-stiffness model over the requested load range. Use [structural verification](references/structural-verification.md) for supports, load combinations, equilibrium and result recovery. Use [nonlinear statics](../fea-multistep-nonlinear/SKILL.md) when stiffness, contact or material state evolves in a way that controls the result.

For a Simcenter Nastran study use [SOL 101 setup](references/sol101.md). For updates to associated CAD geometry or semantic selections use [parametric SOL 101](../simcenter-parametric-sol101/SKILL.md).
