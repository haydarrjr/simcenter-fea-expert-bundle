# Configure and verify Simcenter Nastran SOL 101

Use [structural verification](structural-verification.md) to establish the linear assumptions, support DOFs and response checks. When using a supported SOL 101 contact option, verify the global contact settings and whether each subcase reinitializes or carries forward contact status. Establish compatibility before combining case results. [SOL 101 contact settings and subcase independence](https://docs.sw.siemens.com/en-US/doc/PL20251024315444291.advanced/html/xid1472494?audience=external)

## Establish the effective load case

Resolve [effective deck sets](../../simcenter-nastran/references/deck-and-solutions.md) for each subcase. Audit the selected `LOAD`, `SPC` and `MPC` scope, nested sets, scale factors, frames and applied components. A force and displacement constraint at the same node can act on different DOFs. Investigate warnings using the active component and direction. Verify the resulting support reactions and deflection under the intended load.

When an `MPCFORCES` resultant supports a load-transfer decision, check the effective rigid-element formulation and recover a balancing free-body resultant. Siemens documented incorrect RBE3 recovery with the Lagrange-multiplier formulation through 2406. Check the affected release and output before applying that finding to a current run. [Siemens support advisory PL8809297](https://support.sw.siemens.com/en-US/knowledge-base/PL8809297)

For CAD-associative changes use [parametric SOL 101](../../simcenter-parametric-sol101/SKILL.md). To import an independent deck and check what gets exported from the saved model, see [solver deck round trip](../../designcenter-open-journal-authoring/references/static-deck-roundtrip-2612.md) for the applicable native release.

## Compare the actual results

Use the [solution sequence](../../fea-solver-investigation/references/solution-sequence.md) for the exact exported deck, solver termination and result lineage. Compare signed F06 or [BatchPost](../../batchpost-actions/SKILL.md) output to an applicable independent physical reference. An axial prismatic member under uniform force admits `u = FL/(EA)`, `σ = F/A` and an axial support resultant of `-F`. Choose bending, shear, thermal or prescribed-motion checks when those mechanisms govern.
