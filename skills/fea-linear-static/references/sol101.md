# Simcenter Nastran SOL 101 method

## Select the physical model

Use linear static analysis for a static response within the assumed stiffness and material range. Screen for mechanisms, changing contact, plasticity, large-displacement effects and significant inertia. If using a supported SOL 101 contact option, check the contact controls and subcase initialization behavior for the release. Superposition applies only where stiffness, constraints and contact state remain compatible. [SOL 101 contact settings and subcase independence](https://docs.sw.siemens.com/en-US/doc/PL20251024315444291.advanced/html/xid1472494?audience=external)

Use [model preparation](../../fea-model-preparation/SKILL.md) for the structural representation. Specify effective material/section properties, local frames, intended free/constrained DOFs and actual load application region. Resolve multi-point connections and inspect unexpected grounding or AUTOSPC. Confirm applied forces and moments about a shared datum. Scale the numerical comparison to the actual quantity and dimensional tolerance.

Route a temperature-driven load path to [thermal stress](../../fea-thermal/SKILL.md) for temperature mapping, stress-free reference and restraint. Route a linearized instability factor to [eigenvalue buckling](../../fea-results-interpretation/references/sol103-sol105-quant.md) with its actual preload and buckling state.

## Bind the native and solver states

For a CAD-associative update, use [parametric SOL 101](../../simcenter-parametric-sol101/SKILL.md). For an independent solver deck, use [2612 solver deck import and round trip](../../designcenter-open-journal-authoring/references/static-deck-roundtrip-2612.md) when the deck and installed release support that workflow. Reopened solution and step membership and effective exported `LOAD`, `SPC` and `MPC` serve different checks.

Run the exact qualified deck using [Solution Sequence](../../fea-solver-investigation/references/solution-sequence.md). Review warnings against their actual DOFs and force directions. A load and constraint on the same node can be compatible when they act on different components. Check the solved support and load balance before accepting the setup.

## Verify the result

- Compare signed displacement and reactions in consistent units and frames. For uniform axial loading of a linear prismatic member, use `u = FL/(EA)`, `σ = F/A` and total reaction `-F`. Use a reference appropriate to bending, shear, thermal strain or prescribed support motion when applicable.
- Compare stress at the specified recovery location. Keep elemental, element-nodal and averaged output distinct, especially near material boundaries, point loads and singularities.
- Bind each reported value to its exact subcase, entity, units, and component. Recover independent printed F06 quantities and check the result file through [BatchPost](../../batchpost-actions/SKILL.md) when those fields are available.
