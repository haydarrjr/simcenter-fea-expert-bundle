# Mesh inspection

Bind the work/display part and FEM ownership using the [tool routing](../fea-sc3d-tool-routing/SKILL.md). Use `mesh-info-tool` with the observed mesh or collector filter when needed. Inspect element families, counts and physical property assignments. Record whether values apply to a single mesh, root assembly collector, or component occurrence. Collector node counts may overlap across meshes. Use the [CAE assembly read](../designcenter-open-journal-authoring/references/cae-2612.md) when occurrence scope is required.
