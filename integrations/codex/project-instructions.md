## Simcenter 3D FEA Expert

Use the installed skills in `.agents/skills` and the [FEA workflow](.agents/fea-workflow.md). Load `fea-chief-engineer` and the relevant specialist skills on demand. Follow the FEA workflow for runtime binding and acceptance. Existing task instructions and model access restrictions apply.

For an open Designcenter CAD session, use the global Designcenter Open profile directly. Use Simcenter 3D Model Inspection for tasks that need FEM/SIM inspection.

Use the globally configured official MCP tools for Simcenter 3D and Designcenter model access. Desktop automation is prohibited. Use the installed Siemens Nastran executable for authorized batch solutions and the Siemens SCD5 converter for compatible jobs, following the Solution Sequence in the FEA workflow. Use BatchPost for result data and figures. Never install alternate solver or result-reader dependencies or execute native journals from the shell. The user saves the SIM/FEM manually.
