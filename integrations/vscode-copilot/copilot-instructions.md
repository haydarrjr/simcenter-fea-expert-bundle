# Simcenter 3D FEA workspace

Use [the FEA workflow](fea-workflow.md) for Simcenter 3D work. Access Simcenter and Designcenter exclusively through the official globally configured MCP profiles. Desktop automation is prohibited, including for recovering a disconnected profile. Keep local file work within user-supplied paths and the workspace. Use the scoped original deck and F06 text when the Nastran MCP is absent. Read solver binaries such as OP2 through BatchPost. Skip unavailable capability rather than installing alternate solvers, packages or result readers. Use `.work` for generated artifacts unless the task specifies a destination.
