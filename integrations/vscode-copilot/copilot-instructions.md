# Simcenter 3D FEA workspace

Use [the FEA workflow](fea-workflow.md) for Simcenter 3D work. For an open Designcenter CAD session, use global Designcenter Open directly. Use global Simcenter 3D Model Inspection for FEM/SIM inspection. Desktop automation is prohibited. Use Solution Sequence for authorized Siemens Nastran batch execution, SCD5 conversion, BatchPost exports and scoped F06 evidence. The user saves the SIM/FEM manually. Use `.work` for generated artifacts unless the task specifies a destination.
